# DexScreener & Binance/Bybit Futures Liquidity Monitor 🚀

Мониторинг пулов ликвидности на децентрализованных биржах (DEX) для токенов, торгующихся на фьючерсах Binance и эксклюзивных фьючерсов Bybit.
Обнаруживает ситуации «тихого» вывода ликвидности (Front-running Short Signal / Rug Pull / LP Drain), когда маркетмейкер или инсайдер выводит резервы из DEX-пула, а спотовая/фьючерсная цена еще не успела обвалиться.

---

## 💡 Принцип работы стратегии

1. **Отбор активов (Binance & Bybit)**:
   - **Binance Futures**: активные альткоины с суточным объемом от `$500k` до `$100M`.
   - **Bybit Futures**: поиск эксклюзивных криптотокенов с объемом от `$400k` до `$100M`, которые отсутствуют на Binance.
2. **Поиск пулов на DexScreener**:
   Для каждой монеты находится крупнейший DEX-пул (с ликвидностью от `$80k`). Адреса пулов сохраняются в локальный кэш `data/binance_dex_map.json`.
3. **Молниеносный мониторинг пачками**:
   Пулы опрашиваются пачками до 30 адресов за запрос (DexScreener Multicall API), что занимает считанные секунды без превышения лимитов.
4. **Двойные таймфреймы (Dual Timeframes)**:
   - **⚡ 1-Часовой импульс (1h)**: быстрая реакция на резкий отток ликвидности.
   - **🌊 3-Часовой тренд (3h)**: подтверждение планомерного оттока и макро-сигнал.
   - Каждый таймфрейм имеет независимый кулдаун и отдельную классификацию.
5. **Детекция аномалий (Шорт-сигнал)**:
   - Из пула вывели **более 12%** резерва котируемого токена (`LIQ_DROP_THRESHOLD_PCT <= -12.0%`).
   - Цена еще не успела обвалиться (`MAX_PRICE_DROP_PCT >= -2.5%`).
   - При совпадении условий бот мгновенно отправляет алерт в Telegram с прямой ссылкой на Binance/Bybit и DexScreener, а также сохраняет структурированный JSON в **MongoDB** для квант-анализа.

## 🛠️ Установка и запуск (Poetry)

### 1. Установка зависимостей
Убедитесь, что у вас установлен Poetry:
```bash
poetry install
```

### 2. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
copy .env.example .env
```
Откройте файл `.env` и настройте параметры:
- `TG_BOT_TOKEN` — токен вашего Telegram-бота (от @BotFather)
- `TG_CHAT_ID` — ваш Telegram ID или ID канала
- `CHECK_INTERVAL_SEC` — интервал проверки (по умолчанию 180 сек = 3 мин)
- `LIQ_DROP_THRESHOLD_PCT` — порог вывода ликвидности (по умолчанию `-12.0%`)
- `MAX_PRICE_DROP_PCT` — порог задержки цены (по умолчанию `-2.5%`)

### 3. Проверка Telegram бота
```bash
poetry run dex-monitor test-tg
```

### 4. Первичная сборка карты пулов (опционально)
При первом запуске карта построится автоматически, но ее также можно вызвать вручную:
```bash
poetry run dex-monitor build-map
```

### 5. Разовая проверка (без бесконечного цикла)
Вывести статус пулов и проверить текущие резервы:
```bash
poetry run dex-monitor check-once
```

### 6. Запуск локального веб-дашборда
Открыть интерактивный визуальный Material Design дашборд в браузере:
```bash
poetry run dex-monitor ui
```

### 7. Запуск непрерывного мониторинга
```bash
poetry run dex-monitor run
```

## 📂 Структура проекта

```
DexScreener/
├── data/
│   ├── binance_dex_map.json    # Связка: монета Binance/Bybit -> DEX-пул
│   └── pools_state.json        # Предыдущие снимки резервов и цен
├── src/
│   └── dex_screener/
│       ├── __init__.py
│       ├── binance.py          # API Binance Futures, нормализация тикеров
│       ├── bybit.py            # API Bybit Futures, фильтрация эксклюзивных монет
│       ├── cli.py              # Консольный интерфейс (run, build-map, check-once, ui)
│       ├── config.py           # Настройки pydantic-settings и .env
│       ├── dexscreener.py      # DexScreener API (поиск, батчи, безопасный парсинг)
│       ├── mongo.py            # Интеграция с MongoDB для квант-анализа сигналов
│       ├── monitor.py          # Движок мониторинга и Dual Timeframe (1h/3h) сигналов
│       ├── notifier.py         # Telegram-уведомления (HTML) и Rich-консоль
│       └── storage.py          # Атомарное сохранение JSON файлов
├── web/
│   ├── favicon.ico
│   └── index.html              # Material Design Dashboard
├── .env.example
├── pyproject.toml
└── README.md
```
